## Инструкция по запуску и формат входных параметров

Трафик представляется как последовательность пакетов, у каждого пакета есть:

- время прихода от начала симуляции, с
- размер пакета, байт

C++ часть генерирует csv-файл с результатами моделирования. Python часть читает этот csv-файл, строит графики и рассчитывает характеристики трафика.

Выходной csv имеет формат без заголовка:

```
arrival_time, packet_size
```

где:

- `arrival_time` - время прихода пакета от начала симуляции, с;
- `packet_size` - размер пакета, байт.

В коде csv сохраняется в папку:

```
data/<model_name>/<input_file_name>_simtime_<simulation_time>_traffic.csv
```

Например, для файла `test_config/equal.txt` и времени симуляции `11.0` результат будет сохранён примерно так:

```
data/equal/equal_simtime_11.0_traffic.csv
```

####  Формат входного файла

На вход программе `traffic_model` передаётся путь к текстовому файлу. Файл содержит две строки.

```
<simulation_time>
<model_name>: <parameter_1> <parameter_2> ...
```

где:

- `simulation_time` - время симуляции в секундах;
- `model_name` - имя модели трафика;
- после двоеточия `:` записываются параметры выбранной модели через пробел.

Пример:

```
11.0
equal: 10 512
```

#### Модели

###### Равномерная модель `equal`

В равномерной модели все пакеты имеют одинаковый размер, а задержка между соседними пакетами постоянна.

**Формат строки модели**

```
equal: <interval_sec> <packet_size_bytes>
```

| Параметр | Смысл | Ограничение |
|---|---|---|
| `interval_sec` | фиксированный интервал между пакетами, с | `> 0` |
| `packet_size_bytes` | размер каждого пакета, байт | `> 0` |

*Пример входного файла*

```
11.0
equal: 1.0 512
```

###### Пуассоновская модель `poisson`

В пуассоновской модели интервал между пакетами задаётся распределением Пуассона, а размер пакета задаётся экспоненциальным распределением с ограничением сверху через `MTU`.

**Формат строки модели**

```
poisson: <interval_lambda> <size_lambda> <mtu_bytes>
```


| Параметр | Смысл | Ограничение |
|---|---|---|
| `interval_lambda` | параметр распределения Пуассона для задержек между пакетами | `> 0` |
| `size_lambda` | параметр экспоненциального распределения для размера пакета | `> 0` |
| `mtu_bytes` | максимальный размер пакета, байт | `> 0` |

*Пример входного файла*

```
120.0
poisson: 2 0.002 1500
```

###### Модель Парето `pareto`

Модель Парето используется для описания трафика с редкими, но большими задержками. Такое распределение имеет «тяжёлый хвост»: большинство интервалов относительно небольшие, но иногда появляются очень большие интервалы.

В этой реализации распределение Парето используется для задержек между пакетами. Размер пакета фиксированный.

Пусть случайная задержка между пакетами равна $X$. Тогда:

$$
X \sim \operatorname{Pareto}(x_m, \alpha),
$$

где $x_m$ - минимально возможная задержка, а $\alpha$ - параметр формы распределения.

Функция распределения имеет вид:

$$
F_X(x) = 1 - \left(\frac{x_m}{x}\right)^\alpha, \qquad x \geq x_m.
$$

Плотность распределения:

$$
f_X(x) = \frac{\alpha x_m^\alpha}{x^{\alpha + 1}}, \qquad x \geq x_m.
$$

**Формат строки модели**

```
pareto: <min_interval_sec> <shape_alpha> <packet_size_bytes>
```

Параметры:

| Параметр | Смысл | Ограничение |
|---|---|---|
| `min_interval_sec` | минимальный интервал между пакетами `x_m`, с | `> 0` |
| `shape_alpha` | параметр формы `α` | `> 0` |
| `packet_size_bytes` | фиксированный размер каждого пакета, байт | `> 0` |

- `α <= 1` - средняя задержка теоретически не ограничена
- `1 < α <= 2` - средняя задержка существует, но разброс очень большой
- `α > 2` - существуют и средняя задержка, и дисперсия, поведение трафика стабильнее

*Пример входного файла*

```
120.0
pareto: 0.05 1.5 512
```

#### Запуск C++ части без сборки

Примеры входных файлов расположены в папке `test_configs/`.

Перейти в папку решения:

```bash
cd traffic_model_project
```

Дать права на запуск бинарному файлу, если они ещё не выданы:

```bash
chmod +x traffic_model
```

Запустить модель (пример):

```bash
./traffic_model test_configs/poisson2
```

После запуска программа создаст csv-файлы в папке `data/<model_name>/`.
